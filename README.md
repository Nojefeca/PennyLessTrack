## ⚙️ Instrucciones para instalar y ejecutar el proyecto

   git clone https://github.com/nojefeca/pennyLessTrack.git

2. **Acceder al repositorio:**
   cd PennyLessTrack

3. **Instalar dependencias:**
   npm install
   
4. **Ejecutar la aplicación:**
   npm run dev
